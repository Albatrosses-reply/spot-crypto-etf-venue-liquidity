# Data

**No raw market data is redistributed here.** The analysis uses market data
from cryptocurrency exchanges, Yahoo Finance and Farside Investors, whose
terms of use do not permit wholesale redistribution. This repository ships the
code that acquires and processes that data, and the estimation output derived
from it, so every result stays reproducible.

## Sources and how to reacquire

Set the project root once:

```bash
export CRYPTO1_ROOT="$(pwd)"
```

### 1. Hourly spot OHLCV — eight exchanges via `ccxt`

Binance, Bitfinex, Bitstamp, Bybit, Coinbase, Gemini, OKX, Poloniex. Public
REST endpoints, no API key.

```bash
python scripts/fetch_ccxt_ohlcv.py
```

### 2. Kraken — manual download

Kraken's public endpoint does not serve history deep enough for this sample,
so the Kraken series was **not** collected through `ccxt`. It comes from
Kraken's own historical-data distribution:

> <https://support.kraken.com/articles/360047543791-downloadable-historical-market-data-time-and-sales->

Download the OHLCVT archive, unpack it, then:

```bash
export KRAKEN_DIR=/path/to/Kraken_OHLCVT/master_q4
python scripts/import_kraken_csv.py
```

The importer normalises the CSVs into the same schema as the `ccxt` pull, so
the rest of the pipeline is unchanged.

### 3. ETF creation/redemption flows — Farside Investors

```bash
python scripts/fetch_etf_flows.py
```

### 4. ETF wrapper dollar volume — Yahoo Finance

Daily close × shares traded, per wrapper ticker.

```bash
python scripts/fetch_etf_prices.py
```

Yahoo Finance's terms prohibit redistribution of the retrieved series, which
is why it is fetched rather than shipped.

## Building the panel

```bash
python scripts/build_revision_panel.py   # -> panel_1h_revision.parquet, metrics_1h_revision.parquet
python scripts/fix_volume_units.py       # venue-specific volume-unit correction
```

One quote series is kept per asset-venue-date by the priority
USD > USDT > USDC > FDUSD.

## Running the estimation

`run_revision_did.py` must run first: besides the difference-in-differences,
triple-difference and event-study output, it writes the daily panel that the
later scripts consume.

```bash
python scripts/run_revision_did.py           # DiD, triple-difference, event study, descriptives
python scripts/run_mechanism_tests.py        # ETF-wrapper-volume interaction
python scripts/mechanism_falsification.py    # cross-asset falsification
python scripts/mechanism_robustness.py       # per-venue split, pre-era placebo
python scripts/compute_commonality.py        # cross-venue commonality series
python scripts/commonality_robustness.py     # placebo dates, window length, leave-one-out
python scripts/commonality_regime_shift.py   # era-level Newey--West comparison
python scripts/eth_launch_safety.py          # Ether-launch window sensitivity
python scripts/reviewer_newcalcs.py          # N1-N7: MDE, two-way clustering, randomization
                                             # inference, Ether DDD, US-vs-offshore pooled test,
                                             # falsification robustness, commonality permutations,
                                             # venue event study
```

## Rebuilding the exhibits

`results/` ships populated, so this needs no network access and no raw data:

```bash
pip install -r requirements.txt
python exhibits/make_exhibits.py          # -> exhibits/output/
python exhibits/make_fig4_falsification.py  # two-panel Figure 4
```

The regenerated Tables 2, 3 and 6 match the typeset manuscript on all 149
numbers, row labels included.

## What is not here

| Excluded | Why |
|---|---|
| `data/raw/`, `data/interim/`, `data/revision/` | Raw and near-raw OHLCV from nine exchange APIs |
| `daily_revision.parquet` | Daily panel; retains a raw `close` column. Regenerated by `run_revision_did.py` |

Two of the excluded files also exceed GitHub's 100 MB per-file limit.
